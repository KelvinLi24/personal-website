Issued by: Department of Computing (COMP), The Hong Kong Polytechnic University & Computer Education Research Association of Chinese Universities

View full FerryX project details

Developed FerryX, a SwiftUI AI family companionship and memory-care app. Built a provider-agnostic AI layer enabling users to connect external AI APIs or download app-provided lightweight local models for private/offline use, with MLX, BM25/RAG, persona memories, chat-history import, STT/TTS, and local databases. Champion (Hong Kong Regional Final), Jul 2025

Issued by: The Hong Kong Polytechnic University Department of Computing (PolyU COMP) & iOS Club

View full MemoSpace project details

Led the development of MemoSpace, an end-to-end immersive memory preservation platform integrating 3D Gaussian Splatting, XR/WebXR, and AI-driven digital humans. Independently built the MemoLens iOS AR-guided capture app using Swift and ARKit, developed MemoPortal, a Three.js/WebGL-based web platform for 3D point-cloud viewing, and contributed to the Apple Vision Pro immersive XR experience. Designed and implemented the MemoChat digital human module, combining LLM-based conversational AI, Retrieval-Augmented Generation (RAG), memory database, persona management, chatlog import, STT/TTS, voice cloning, lip-sync orchestration, and avatar-based storytelling to enable interactive, memory-grounded conversations. Managed system architecture, module integration, 3D scene data collection, and user evaluation. The project won China Collegiate Computing Contest (Mobile Application Innovation Contest 2025) Hong Kong Regional Final Champion, National Final Second Prize, and was accepted as a short paper at APSCE TBICS on AI, MetaACES 2026.

More Technical Projects

Cloud Application Project
Web & Cloud Application

CampusTradeSphereYouTube

Developed and deployed CampusTradeSphere, a cloud-hosted e-commerce-style campus marketplace platform for student trading and rental workflows. Worked on frontend–backend integration, REST API implementation, backend services, SQLite database management, AWS deployment, and system verification using JavaScript, Node.js, Express, Python Flask, Nginx, AWS EC2, S3, CloudWatch, and Apache Spark on EMR. Implemented product listing, cart/checkout, sale and rental order workflows, and an admin analytics dashboard to visualise user activity, GMV, API latency, and live alerts, demonstrating hands-on experience in web application development, API integration, cloud-hosted services, data processing, and operational monitoring.
