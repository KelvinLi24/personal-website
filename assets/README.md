# Generated website assets

`assets/icon.png` is the site/profile avatar.

Portfolio gallery folders under `assets/featured`, `assets/projects`, `assets/teaching-volunteering`, `assets/yunnan-service-learning`, and `assets/newspaper` are generated from `source-images/`.

For new photos, place numbered originals such as `1.jpg`, `2.jpg`, `3.jpg` in the matching `source-images/...` folder. The image build creates responsive WebP files, blur placeholders and an `images.json` manifest for the website.
