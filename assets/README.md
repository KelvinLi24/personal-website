# Avatar image

Place your portrait at `assets/icon.png`. The website uses this file for the header, side navigation, profile card, post avatars, and browser tab icon. If the file is temporarily missing, the initials fallback remains visible.

# Image folders

Each photo post has its own folder.

## How to add images
1. Open the folder for the post.
2. Add images in the display order you want.
3. Name them with consecutive numbers: `1`, `2`, `3`, `4`, ...
4. Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`.
5. You do not need to edit HTML, CSS, or JavaScript.

Examples:
- `1.jpg`
- `2.png`
- `3.webp`

The website automatically tries the supported extensions for each number and stops when the next number is missing.

## Image interaction note
Post gallery images use numbered files as before. The page disables the normal right-click image menu and image dragging for gallery images, and clicking an image does not open a zoom viewer. Carousel arrows, dots, swipe, and double-click Like remain available.
